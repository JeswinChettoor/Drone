Description of some relevant params



- `AHRS_EKF_TYPE`: **Selects which Extended Kalman Filter (EKF) algorithm is actively used by AHRS for state estimation.** — `0`: Disabled (uses legacy DCM), `2`: EKF2 (2nd generation filter; requires `EK2_ENABLE=1`), `3`: EKF3 (3rd generation filter, default for modern firmware; supports optical flow/external nav; requires `EK3_ENABLE=1`), `10`: SITL internal simulation filter, `11`: External AHRS / MicroStrain INS
- `AHRS_GPS_USE`: **Controls whether GPS velocity and position measurements are used by AHRS/EKF for state estimation.** — `0`: Disabled (ignores GPS data, forcing AHRS/EKF into non-GPS dead-reckoning or optical flow/external nav modes), `1`: Enabled (uses GPS measurements for position, velocity, and drift correction when a valid lock is present).
- -`AHRS_ORIENTATION`: **Defines the rotational mounting offset of the autopilot board relative to the vehicle frame.** — `0`: None (standard forward/flat mounting), `1` to `3`: Yaw 45°/90°/135°, `4`: Yaw 180°, `5` to `7`: Yaw 225°/270°/315°, `8`: Roll 180° (upside down), `9` to `15`: Roll 180° combined with Yaw increments, `16`: Pitch 90° (nose down), `24`: Pitch 180° (upside down nose back), `25`: Pitch 270° (nose up), `100`: Custom rotation matrix.
- `AHRS_ORIGIN_ALT`: **Stores the altitude of the AHRS/EKF global origin point (datum) above Mean Sea Level (MSL).** — Range `-200` to `5000` (in meters above sea level; automatically saved/restored for non-GPS/indoor navigation and external localization datums).
- `AHRS_ORIGIN_LAT`: **Stores the latitude coordinate of the AHRS/EKF global reference origin (datum) in decimal degrees.** — Range `-90.0` to `90.0` (positive for North, negative for South; automatically recorded or manually assigned for non-GPS/indoor navigation and external SLAM/VIO systems).
- `AHRS_ORIGIN_LON`: **Stores the longitude coordinate of the AHRS/EKF global reference origin (datum) in decimal degrees.** — Range `-180.0` to `180.0` (positive for East, negative for West; used alongside latitude and altitude to establish the local Cartesian $(X, Y)$ zero-point for non-GPS navigation, indoor SLAM/VIO, and simulation datums).
- `ARMING_ACCTHRESH`: **Maximum acceptable accelerometer measurement variance/disagreement allowed during pre-arm checks.** — `0`: Disabled (skips check), Range `0.00` to `3.00` (in $\text{m/s}^2$, default `0.75`; pre-arm fails with "Accels inconsistent" if multi-IMU readings or gravity vectors deviate beyond this limit while stationary).
- `ARMING_MAGTHRESH`: **Maximum allowed difference in magnetic field strength between multiple internal/external compasses or compared to the expected Earth magnetic field model during pre-arm checks.** — `0`: Disabled (skips compass consistency check), Range `50` to `500` (in milliGauss / millitesla equivalent units, default `100` to `150`; pre-arm fails with "Compasses inconsistent" or "Mag field inconsistent" if readings deviate beyond this threshold).
- `ARMING_NEED_LOC`: **Determines whether an absolute geographic origin/location must be established before allowing the vehicle to arm.** — `0`: Arming allowed without a known global location (standard for manual/altitude modes or testing), `1`: Requires a valid location (physical GPS lock, external vision/SLAM global position, or manually set EKF origin) prior to arming.
- `ARMING_OPTIONS`: **Bitmask specifying specialized behaviors and bypass conditions during arming.** — `0`: Standard arming behavior (default), `1` (Bit 0): Require parameter consistency check on arming, `2` (Bit 1): Arm without require zero throttle check (Plane only), `4` (Bit 2): Disable pre-arm check beep, `8` (Bit 3): Disarm on switch loss / bypass arm checks for fast boot, `16` (Bit 4): Disable motor checks, `32` (Bit 5): Enforce arming checks in manual modes. Values are summed to combine options.
- `ARMING_SKIPCHK`: **Bitmask specifying which pre-arm safety checks should be skipped/bypassed (inverts the legacy `ARMING_CHECK` parameter).** — `0`: Do all checks (no checks skipped, default), `-1`: Skip all checks, or sum bitmask values to bypass specific subsystems (e.g., `1`: Barometer, `2`: Compass, `4`: GPS, `8`: INS/IMU, `16`: Parameters, `32`: RC channels, `64`: Voltage/Battery, `128`: Logging, `256`: Switch, `512`: GPS Config, `1024`: System, `2048`: Mission).
- `ATC_ANGLE_MAX`: **Maximum roll and pitch lean angle allowed in stabilized flight modes (Stabilize, AltHold, Loiter, Auto).** — Range `1000` to `8000` (in centidegrees, default `3000`–`4500` representing 30° to 45°; setting higher values increases maximum speed and maneuverability but requires higher thrust margins to maintain altitude).
- `ATC_RATE_WPY_MAX`: **Sets the maximum rate/slew limit at which the target heading (yaw) can change during automated navigation modes (Auto, Guided, Circle, RTL).** — Range `0.0` (disabled/unconstrained) to `360.0` (in deg/s, default typically `0.0` or `10.0` to `80.0`; formerly `ATC_SLEW_YAW` in centidegrees/s).
- `ATC_RATE_Y_MAX`: **Maximum angular velocity (rotation rate) allowed about the yaw axis in non-Acro attitude control modes (Stabilize, AltHold, Loiter, Auto).** — `0.0`: Disabled / unconstrained (falls back to default limits), Range `0.0` to `720.0` (in deg/s, typically set between `45.0` and `200.0` depending on frame authority and pilot preference).
- `DISARM_DELAY`: **Time delay in seconds before the vehicle automatically disarms after landing or sitting on the ground at minimum throttle.** — `0`: Disabled (never auto-disarms), Range `1` to `127` (in seconds, default `10`; sets the idle waiting period before auto-disarm triggers).
- `EK2_ENABLE`: **Controls whether the 2nd generation Extended Kalman Filter (EKF2) core is loaded and active.** — `0`: Disabled (frees CPU and RAM; standard on modern builds), `1`: Enabled (runs legacy EKF2 estimator).
- `EK3_ENABLE`: **Controls whether the 3rd generation Extended Kalman Filter (EKF3) core is loaded and active.** — `0`: Disabled, `1`: Enabled (activates modern state estimation with support for multiple sources, lane switching, optical flow, and external visual/SLAM odometry).
- `EK3_PRIMARY`: **Selects which EKF3 core instance (lane) is used as the primary estimator for attitude and position control.** — `0`: First IMU/sensor lane (default), `1`: Second IMU lane, `2`: Third IMU lane (the autopilot automatically switches away from this index if a failure or high innovation variance is detected on the active lane).
- `EK3_IMU_MASK`: **Bitmask determining which physical IMU sensors will spawn an independent EKF3 core instance (lane).** — `1` (Bit 0): IMU1 only, `2` (Bit 1): IMU2 only, `3` (Bits 0 & 1): IMU1 and IMU2 (default dual-redundancy configuration), `7` (Bits 0, 1 & 2): IMU1, IMU2, and IMU3 (triple redundancy).
- `EK3_SRC_OPTIONS`: **Bitmask setting operational fusion options for source transitions.** — `0`: None/Default, `1` (Bit 0): Fuse absolute yaw from source when resetting position.
    
- `EK3_SRC1_POSXY`: **Primary source for horizontal (X/Y) position estimation.** — `0`: None, `3`: GPS, `4`: Beacon, `6`: External Nav (Vision/SLAM/VICON).
    
- `EK3_SRC1_VELXY`: **Primary source for horizontal (X/Y) velocity estimation.** — `0`: None, `3`: GPS, `4`: Beacon, `5`: Optical Flow, `6`: External Nav.
    
- `EK3_SRC1_POSZ`: **Primary source for vertical (Z) position/altitude estimation.** — `0`: None, `1`: Barometer, `2`: RangeFinder (Sonar/LiDAR), `3`: GPS, `4`: Beacon, `6`: External Nav.
    
- `EK3_SRC1_VELZ`: **Primary source for vertical (Z) velocity/climb-rate estimation.** — `0`: None, `3`: GPS, `4`: Beacon, `6`: External Nav.
    
- `EK3_SRC1_YAW`: **Primary source for heading/yaw estimation.** — `0`: None, `1`: Compass (Magnetometer), `2`: GPS Heading (dual-antenna), `3`: GPS Ground Course, `6`: External Nav, `8`: GSFC (Compass with wind estimation).
    
- `EK3_SRC2_POSXY` to `EK3_SRC2_YAW`: **Secondary source set (same values as SRC1).** — Configures the backup sensor set activated manually via an RC switch or auxiliary function (`RCx_OPTION = 90` for Source Set 2).
    
- `EK3_SRC3_POSXY` to `EK3_SRC3_YAW`: **Tertiary source set (same values as SRC1).** — Configures the fallback sensor set activated manually via an RC switch or auxiliary function (`RCx_OPTION = 90` for Source Set 3).
- `EK3_ENABLE`: **Controls whether the 3rd generation Extended Kalman Filter core is initialized and run.** — `0`: Disabled, `1`: Enabled (standard modern state estimator).
- - `EK3_FLOW_DELAY`: **Time delay compensation between Optical Flow image capture timestamps and IMU data.** — Range `0` to `250` (in milliseconds, default `10`).
- - `FENCE_ACTION`: **Vehicle behavior triggered when a configured geofence boundary is breached.** — `0`: Report only (warning to GCS), `1`: RTL / Return to Launch or Land (default), `2`: Land immediately, `3`: SmartRTL or RTL, `4`: Brake / Loiter in place, `5`: SmartRTL or Land.
- - `FENCE_ALT_MAX`: **Maximum altitude limit above home/datum for the geofence ceiling.** — Range `0` to `1000` (in meters, default `100.0`; breaching forces the configured `FENCE_ACTION`).
- - `FENCE_ALT_MAX_TP`: **Altitude frame type used for interpreting the geofence maximum ceiling altitude.** — `0`: Relative to Home, `1`: Above Terrain / AGL (default), `2`: Above Mean Sea Level (AMSL).
- - `FENCE_ALT_MIN`: **Minimum altitude limit for the geofence floor (useful for floor avoidance or subterranean flight limits).** — Range `-100` to `100` (in meters, default `-10.0`).
- - `FENCE_RADIUS`: **Maximum allowed horizontal circular distance from the home position.** — Range `0` to `10000` (in meters, default `300.0`; active when `FENCE_TYPE` includes circular fence).
- - `FLOW_TYPE`: **Driver selection for the onboard optical flow camera/sensor module.** — `0`: None (default), `1`: CXOF (serial), `2`: PX4Flow (I2C/serial), `3`: PixArt (SPI), `4`: SITL simulation flow, `5`: HereFlow / DroneCAN, `6`: PWM-based, `7`: UART/Serial flow sensor.
- - `FRAME_CLASS`: **High-level multirotor frame classification geometry.** — `0`: Undefined, `1`: Quad (default as set here), `2`: Hexa, `3`: Octa, `4`: OctaQuad (X8), `5`: Y6, `6`: Heli, `7`: Tri, `8`: Single/Coax Copter, `12`: DodecaHexa.
- - `FRAME_TYPE`: **Motor layout orientation configuration within the chosen frame class.** — `0`: Plus (+), `1`: Cross (X, default as set here), `2`: V-frame, `3`: H-frame, `12`: Betaflight X layout.
- - `FS_EKF_ACTION`: **Action executed when Extended Kalman Filter variance thresholds trigger an EKF failsafe.** — `1`: Land mode (default), `2`: AltHold mode, `3`: Land mode even in manual modes.
- - `FS_GCS_ENABLE`: **Action triggered when Ground Control Station MAVLink telemetry heartbeat connection is lost.** — `0`: Disabled (default), `1`: RTL / Return to Launch, `2`: Continue AUTO mission else RTL, `3`: SmartRTL or RTL, `4`: SmartRTL or Land, `5`: Land immediately.
- - `GND_EFFECT_COMP`: **Enables compensation for aerodynamic ground effect barometric pressure disturbances during takeoff/landing.** — `0`: Disabled, `1`: Enabled (default; uses EKF height estimation to correct baro pressure rises).
- - `GPS1_TYPE`: **Selects communication protocol and receiver type for primary GPS instance.** — `0`: None (disabled as set here), `1`: Auto detect, `2`: u-blox, `5`: NMEA, `9`: DroneCAN/UAVCAN, `14`: SBP, `17`: Septentrio.
- - `GPS2_TYPE`: **Selects protocol and driver type for secondary/backup GPS instance.** — `0`: None (disabled as set here; values match `GPS1_TYPE`).
- - `GUID_OPTIONS`: **Bitmask configuring specialized behaviors while operating in GUIDED flight mode.** — `0`: Standard guided behavior (default), `1`: Allow arming directly in Guided mode, `4`: Ignore yaw input in Guided velocity control.
- - `INITIAL_MODE`: **Flight mode enforced immediately upon system boot and initialization.** — `0`: Standard startup (stabilize/default mode), Range `0` to `25` (numerical flight mode ID).
- - `INS_USE`: **Enables the primary IMU instance for AHRS/EKF state estimation.** — `0`: Disabled, `1`: Enabled (default).
- - `INS_USE2`: **Enables the secondary IMU instance for dual-redundancy AHRS/EKF state estimation.** — `0`: Disabled, `1`: Enabled (default).
- - `LOIT_ACC_MAX_M`: **Maximum horizontal acceleration allowed in Loiter mode during stick inputs.** — Range `0.5` to `10.0` (in $\text{m/s}^2$, default `5.0`; higher values make loiter stick response sharper).
- - `LOIT_ANG_MAX`: **Maximum lean angle allowed in Loiter mode when overriding standard limits.** — `0.0`: Use `ATC_ANGLE_MAX` limit (default), Range `10.0` to `45.0` (in degrees).
- - `SIM_FLOW_ENABLE`: **Controls whether a synthetic downward-facing optical flow sensor is simulated in SITL.** — `0`: Disabled (default), `1`: Enabled.
- - `SIM_FLOW_POS_X` to `SIM_FLOW_POS_Z`: **Physical 3D lever-arm offset distance from vehicle Center of Gravity (CG) to simulated optical flow sensor in SITL.** — Range `-5.0` to `5.0` (in meters, default `0.0`).
    
- `SIM_FLOW_RATE`: **Output update frequency of simulated optical flow sensor frames in SITL.** — Range `1` to `100` (in Hz, default `10`).
    
- `SIM_FLOW_RND`: **Measurement noise amplitude injected into simulated optical flow velocity readings in SITL.** — Range `0.0` to `1.0` (in $\text{rad/s}$, default `0.05`).
- - `SIM_IMU_COUNT`: **Total number of independent simulated IMU sensor instances spawned in SITL.** — Range `1` to `3` (integer count, default `2`; configures single, dual, or triple simulated IMU redundancy).
- - `SIM_IMU_ORIENT`: **Simulated board / IMU mounting orientation offset in SITL.** — `0`: None / forward-facing level (default), `1` to `38`: Standard ArduPilot AHRS orientation rotations (e.g., `8`: Pitch 180°, `4`: Yaw 180°).
- - `SIM_MAG1_ORIENT`: **Simulated physical mounting orientation rotation offset for Magnetometer 1 in SITL.** — `0`: None / ROTATION_NONE (default), `1` to `38`: Standard ArduPilot AHRS sensor rotation indices (e.g., `4`: Yaw 180°, `8`: Roll 180°).
- - `WP_RADIUS_M`: **Acceptance radius distance around a target waypoint.** — Range `0.1` to `20.0` (in meters, default `2.00`; vehicle marks waypoint reached when inside this sphere).
- - `WP_RFND_USE`: **Enables rangefinder/LiDAR distance fusion for terrain-following and altitude control in autonomous missions.** — `0`: Use barometer/GPS altitude only, `1`: Use rangefinder for terrain-following when within reliable sensor range (default).
- - `WP_YAW_BEHAVIOR`: **Vehicle heading orientation behavior during autonomous waypoint navigation.** — `0`: Do not change yaw (maintain current heading), `1`: Face next waypoint (align nose towards target), `2`: Face next waypoint except on RTL (default), `3`: Face along GPS ground course trajectory.
